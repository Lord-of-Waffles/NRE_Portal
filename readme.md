# Project Summary / Overview

### Project Name: NRE_Portal

### Description:
NRE_Portal is a web application designed to provide an interactive overview of renewable energy production in the Valais region of Switzerland. The platform allows users to visualize the generation of electricity from multiple renewable sources over the years, including photovoltaic panels, hydroelectric dams, wind turbines, and biogas installations.

### Main Features:

* **Global Energy Production Dashboard:** Displays total renewable energy production in Valais over time.

* **Individual Energy Type Pages:** Dedicated pages for photovoltaic, hydroelectric, wind, and biogas production, providing detailed statistics and historical trends.

* **Private Installation Tracking:** Users can register their own private renewable energy installations, that will add up to the overall production of energy.

### Technologies Used:

* **Backend:** C# with .NET 8

* **Frontend:** ASP.NET MVC (for interactive dashboards and pages)

* **Containerization:** Docker for creating reproducible builds

* **CI/CD:** GitHub Actions for automated builds, tests, and Docker image publication

* **Cloud Deployment:** Google Cloud Platform for hosting and deployment

* **Version Control & Project Management:** GitHub (repositories, branching strategy, Issues, Projects, Wiki)

### ALM Integration:
The project integrates multiple stages of Application Lifecycle Management (ALM) within GitHub:

* **Version Control:** Git with main, dev, and feature branches

* **Continuous Integration / Continuous Deployment (CI/CD):** Automated build, testing, and Docker image publication pipelines

* **Issue Tracking & Agile Management:** GitHub Issues, Milestones, and Project Boards for planning and progress tracking

* **Documentation & Team Communication:** GitHub Wiki for project documentation and GitHub Discussions for team collaboration

### Objective:
NRE_Portal aims to provide an accessible and interactive tool to explore renewable energy trends in Valais.
